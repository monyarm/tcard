# tcard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tcard fireball | tp` prints one ASCII card of a 5e spell, 32 columns wide, scripted end to end from 5e.tools data.

**Architecture:** argv is resolved to `(system, kind, name)`; a source adapter turns a 5e.tools JSON record into a `Card`; `render/layout.py` turns the `Card` into width-checked `Line`s; `render/text.py` joins them into bytes for stdout. A PNG backend consumes the same `Line`s later and is not part of v1.

**Tech Stack:** Python 3.11+ stdlib only (`argparse`, `urllib`, `tomllib`, `hashlib`, `json`). Tests are plain `assert` functions run by `tests/run.py`, because `pytest` is not installed in this environment.

**Spec:** `docs/superpowers/specs/2026-11-18-tcard.md`

## Global Constraints

- Output is pure ASCII, 7-bit, before it reaches stdout. No ANSI, no box drawing, no bullets.
- Every emitted line is `<= cols` characters; layout raises rather than truncating.
- `cols` default is 32, overridable with `--cols`.
- Exit codes: 0 ok, 1 no unique match, 2 usage/config, 3 cache/network.
- Errors go to stderr, one line, never a traceback.
- stdlib only in the shipped package. No `requests`, no `Pillow` until the PNG task.
- Cache lives at `$XDG_CACHE_HOME/tcard/5e/`, config at `$XDG_CONFIG_HOME/tcard/config.toml`.
- Data source is `https://5e.tools/data/spells/`; the GitHub mirror is DMCA-blocked.

## Review Focus

Each line is pinned to a test in the task that owns the code.

1. Non-ASCII prose or names (curly quotes, em dash, `x` multiplication sign) reaching stdout as `?` or black blocks — `fold` strips or transliterates, and layout asserts ASCII.
2. A single token longer than `cols` (a URL or a long material component) producing an over-wide line — `wrap` hard-breaks it.
3. Duplicate names: Fireball in both PHB and XPHB; Shield as a spell and (later) an item — deterministic preference, `--source` override, `--all` listing.
4. Record shapes that are not plain strings: `table` and `list` entry nodes, and tags outside the 22 known ones — no traceback, readable text or graceful drop.
5. Missing or half-downloaded cache with no network — exit 3 with a one-line message.
